# Security and privacy reports

Please **do not open a public issue** for anything involving a vulnerability or exposed data.

Report privately through GitHub: **Security → Report a vulnerability** on this repository
(GitHub private vulnerability reporting). Include what you found and how to reproduce it, but
**do not include any real resident data** in the report.

You can expect an acknowledgement within 7 days.

Scope: this code and the reference deployment. If you run your own instance, you are responsible
for its hosting environment (see [PRIVACY.md](PRIVACY.md)).
